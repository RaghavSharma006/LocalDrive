# Security policy

LocalDrive is a Windows-only project and its TeraBox connector uses an unofficial backend. Do not send passwords, TeraBox cookies, DPAPI files, signed URLs, or private account data in an issue or pull request.

For a suspected security issue, contact the repository owner privately through GitHub's profile contact options. Include a short description and steps to reproduce, with account identifiers and secrets removed. Do not publish an exploit or other users' data before a fix is available.

Connection diagnostic files are stored under `%LOCALAPPDATA%\LocalDrive`. Review and redact them before sharing. LocalDrive is not a substitute for a backup; verify that important changes have uploaded before disconnecting.
